# Examples

All files in this folder were generated by `scripts/make_examples.sh` with the `rglist` tool. In each
entry:

* `G_n(g, f)` is a Riordan labeling of the graph;
* the drawing shows the vertices clockwise in Riordan order;
* `B` is the lower-triangular Riordan matrix `B[i][j] = [t^i] g f^j` (rows `0..n−2`);
* the adjacency lower triangle repeats `B` one row lower (`A[i][j] = B[i−2][j−1]`).

| listing | graphs |
|---|---|
| [unlabeled/order_1.md](unlabeled/order_1.md) … [unlabeled/order_6.md](unlabeled/order_6.md) | all unlabeled Riordan graphs of order 1–6 (1, 2, 4, 11, 30, 109) |
| [labeled/order_2.md](labeled/order_2.md), [order_3](labeled/order_3.md), [order_4](labeled/order_4.md) | all labeled Riordan graphs of order 2–4 (2, 6, 22) |
| [complement/order_4.md](complement/order_4.md), [5](complement/order_5.md), [6](complement/order_6.md) | unlabeled Riordan graphs whose complement is Riordan (11, 26, 90) |
| [complement/labeled_order_4.md](complement/labeled_order_4.md), [5](complement/labeled_order_5.md), [6](complement/labeled_order_6.md) | labeled Riordan graphs whose complement is Riordan in the same labeling (12, 28, 92) |
| [self_complementary/](self_complementary/) | self-complementary Riordan graphs of order 4, 5, 8, 9, 12 (1, 2, 1, 1, 2) |
| [csv/](csv/) | CSV listings: unlabeled for orders 1–9, labeled for orders 1–7 |

CSV columns (unlabeled): `k, n, g, f, edges, graph6, degree_sequence, riordan_labelings,
complement_riordan, self_complementary`. Edges are written as pairs of vertex numbers, e.g. `12 24`
means the edges {1,2} and {2,4}.

To produce any other listing, for example all connected unlabeled Riordan graphs of order 7 with
drawings:

```sh
build/rglist 7 --filter connected --format markdown --svg order7 > order7.md
```
